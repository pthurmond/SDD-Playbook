# SDD Guide

This guide is part of a personal exploration, not a claim that SDD is already Patrick's daily operating model or an official WPP practice. Start with [Position, Scope, and Boundaries](00-position-and-scope.md) for the work/play distinction, JDD relationship, AI limits, and guardrails.

## Learning Path

1. [Position, Scope, and Boundaries](00-position-and-scope.md) - what this repository claims, what it does not, and how JDD relates.
2. [Foundations](01-foundations.md) - definitions, maturity levels, and why SDD matters now.
3. [Workflow](02-workflow.md) - the lifecycle from problem framing to spec maintenance.
4. [Writing Great Specs](03-writing-great-specs.md) - requirement IDs, acceptance criteria, EARS patterns, and spec quality.
5. [AI Agent Workflow](04-ai-agent-workflow.md) - how to use specs to constrain agent work.
6. [Adoption Playbook](05-adoption-playbook.md) - a 30/60/90-day rollout path.
7. [Glossary](06-glossary.md) - core terms and definitions.
8. [When Not to Use SDD](07-when-not-to-use-sdd.md) - how to avoid over-specifying simple work.
9. [Agent Instructions and SDD Skills](08-agent-instructions-and-skills.md) - how to use `AGENTS.md`, task briefs, and reusable skills together.
10. [Multi-Agent SDD](09-multi-agent-sdd.md) - how to coordinate clarifier, planner, test, implementer, and reviewer agents.
11. [Human-in-the-Loop SDD](10-human-in-the-loop.md) - where human judgment belongs in SDD and orchestration.
12. [Advanced Agent Orchestration](orchestration/README.md) - a deep dive into building agent loops, programmatic routing, UI tools, design patterns, and observability.

Use the [decision ladder](../decision-ladder.md) alongside this guide to decide how much rigor a project needs.
